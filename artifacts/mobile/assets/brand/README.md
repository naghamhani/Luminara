# Luminara brand — the "Kept Flame"

A single flat flame **cupped by two hands**. Three meanings in one shape:

- **Warmth** — a companion for 3am feeds and hard postpartum nights.
- **Clarity** — it turns scattered health data into something you can see by.
- **Held / yours** — the cupped hands say *protected, private, on your device*.

Deliberately **no clouds** (they read as cloud-storage and undercut the
on-device privacy promise) and **no candlestick** (a lit candle can read as a
vigil / mourning — a real risk next to PPD and pregnancy loss). The flame alone,
held, reads as *a light kept for you*.

## Files

| File | Use |
|---|---|
| `luminara-icon.svg` | App-tile / marketing icon (indigo squircle) |
| `luminara-mark.svg` | Flame mark on transparent — place on any surface |
| `luminara-mark-mono.svg` | One-colour: press, emboss, watermark, disabled |
| `luminara-wordmark.svg` | "Luminara" with the flame as the dot of the *i* |
| `luminara-lockup.svg` | Horizontal badge + wordmark + HEALTH |

In-app, **don't use these files directly** — render
[`components/LuminaraLogo.tsx`](../../components/LuminaraLogo.tsx), which is the
single source of truth (crisp at any size, no raster). The SVGs here are the
design masters; the store PNGs are regenerated by `scripts/` (see below).

## Colour

| Token | Hex | Role |
|---|---|---|
| Indigo | `#5168B4` | Hero, trust, badge background |
| **Candle Amber** | `#F6A94C` | **The one owned accent** — flame, primary actions, active states |
| Spark | `#FFE7BE` | Flame inner highlight only |
| Ink | `#1C2236` | Text |
| Lavender | `#F4F6FD` | Canvas, cradle-on-dark |
| Teal | `#3AAFA9` | **Demoted** — data viz / success only |

Rule of thumb: indigo carries the calm; **amber is rationed** and means "pay
attention here." Keep purple and teal to the cycle-phase system and charts.

## Clear space & minimums

- Clear space around the mark = the height of the flame's inner spark on all sides.
- Minimum legible size: **20px** (badge) / **16px** (mono). Below that, drop the
  cradle stroke and show the flame alone.

## Regenerating the store PNGs

`app.json` points `icon` and `splash` at `assets/luminara-logo.png`. To rebuild:

- **No install:** open [`scripts/generate-app-icon.html`](../../scripts/generate-app-icon.html)
  in a browser → click the download buttons → drop the PNGs into `assets/`.
- **CI / scripted:** `npm i -D sharp && node scripts/generate-icons.mjs`.

The geometry is duplicated in four places on purpose (component, SVG masters,
both scripts). If you change the flame path, change it everywhere — each file
notes it.
